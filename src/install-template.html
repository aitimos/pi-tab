保存到书签栏

Pi Tab
拖到书签栏，在其他网页继续使用
  1. 显示浏览器书签栏
    Mac ⌘ ⇧ BWindows Ctrl Shift B
  2. 拖动上方按钮，保存书签

    将按钮拖到浏览器书签栏后松开。也可以先保存书签，使用时再填写模型信息。

  3. 打开网页，点击书签

    按提示补全模型信息，就能在对话窗口中提问或描述任务。

模型密钥会保存在书签中，也可能随浏览器同步。请勿分享包含密钥的书签。

保存新的模型设置后，请将上方按钮重新拖到书签栏，替换旧书签。

手动添加书签

复制下方地址，在浏览器的书签管理器中新建书签。填写名称，将地址粘贴到新书签的“网址”栏，再保存。

安装 Chrome 扩展

下载扩展包
  1. 解压扩展包

    得到 pi-tab-extension 文件夹。

  2. 打开扩展程序页面

    在地址栏输入 chrome://extensions，开启开发者模式。

  3. 加载并启用

    点击“加载已解压的扩展程序”，选择 pi-tab-extension 文件夹，再点击工具栏中的 Pi Tab 图标。

使用帮助

如何填写模型信息？

在模型服务商的网站中获取密钥（API Key）、接口地址和模型名称，并按说明选择接口类型。请选择支持工具调用的模型，Pi Tab 需要这项能力来读取和操作页面。

无法打开或连接模型？

请在普通网页中打开 Pi Tab，浏览器设置页等内部页面无法使用。若对话窗口未出现，可能是网页禁止运行书签脚本。若无法获得回复，请核对模型信息，并向服务商确认接口是否允许网页直接访问（CORS）。

Pi TabAI 可读取并操作页面，请在信任的网页使用。
