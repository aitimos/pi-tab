保存到书签栏

Pi Tab
拖到书签栏，在其他网页继续使用
  1. 显示浏览器书签栏
    Mac ⌘ ⇧ BWindows Ctrl Shift B
  2. 拖动上方按钮，保存书签

    先在左侧配置模型，再拖入书签，即可在其他网站复用。

  3. 打开网页，点击书签

    在对话窗口中提问或描述任务。空白书签需先配置模型。

模型密钥会保存在书签中，也可能随浏览器同步。请勿分享包含密钥的书签。

本页保存的全部模型、供应商和当前默认选择都会随书签保存。其他网站的独立配置不会被覆盖。

手动添加书签

复制下方地址，在浏览器的书签管理器中新建书签。填写名称，将地址粘贴到新书签的“网址”栏，再保存。

安装 Chrome 扩展

下载扩展包
  1. 解压扩展包

    得到 pi-tab-extension 文件夹。更新时替换原目录文件。

  2. 打开扩展程序页面

    在地址栏输入 chrome://extensions，开启开发者模式。

  3. 加载并启用

    点击“加载已解压的扩展程序”，选择 pi-tab-extension 文件夹，在普通网页点击工具栏中的 Pi Tab 图标并配置模型。更新后需重新加载扩展并刷新网页。

使用帮助

如何添加和切换模型？

首次使用填写服务商提供的接口类型、地址和密钥，获取模型后选择并保存。以后从输入框下方的模型下拉切换；「添加模型」可复用提供商并搜索或手填模型 ID；在提供商旁点击「添加提供商」可保存新的连接信息。请选择支持工具调用的模型。

会话保存在哪里？刷新会怎样？

扩展会话保存在本机，按完整域名分组，同域的路径、查询参数和标签页共享列表，模型配置跨网站共享。已启用标签页刷新后自动恢复，页面操作仍需要可用的目标标签页。刷新后重新点击书签默认打开空白会话，有未完成任务时恢复该任务；历史仍保留在会话列表，同源标签页并发使用时可能有独立记录。两种模式的记录不自动合并，也不上传云端同步。

如何管理会话和主题？

顶部可新建对话、新开窗口和切换会话，新窗口使用空白会话并继承模型配置。标题在首轮回复后自动概括并保存，圆环表示会话正在运行。删除时点击会话右侧图标并确认，运行中的任务需先停止。「Pi 设置」中的主题可选跟随、浅色、深色，默认跟随网页或浏览器；设置分为常规、指令、执行三类。

如何跨标签页协作？

从 Chrome 工具栏的 Pi Tab 扩展图标启动。Agent 可用 tab_open 打开标签页并创建独立会话，通过 tab_send 发任务、tab_read 读结果。书签中的 agent_spawn 只创建使用当前页面的新会话，不会打开标签页；安装扩展也不会改变已有书签会话的能力。

可以发送文件和图片吗？

点击输入框旁的附件图标，或拖入文件、粘贴图片。支持 UTF-8 文本和代码文件，PNG、JPEG、WebP、GIF 图片需模型支持视觉输入。最多 8 个附件，单个 5 MB，总计 10 MB；暂不解析 PDF、Office 文档、音视频和压缩包。附件随消息发送到配置的模型服务并保存到会话。

支持账号登录吗？

点击“账户登录”，按提供商提示授权，无需本地服务。书签登录状态仅在当前网站保存，不会随书签导出；扩展登录状态可跨网站复用。书签登录需要网页允许相应脚本和网络请求。

无法打开或连接模型？

扩展用于普通 HTTP 和 HTTPS 网页，不支持本地文件、浏览器设置页或扩展商店。书签可能被网页安全策略拦截，模型接口还需允许网页跨域访问（CORS）。扩展从后台请求模型；连接失败时请核对接口地址、凭据和模型权限。
