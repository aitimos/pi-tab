## 目标和基线

同站、子域、跨站均能显式选择原对话，在当前文档继续。历史来源、执行文档和观察者分离；不迁移来源消息库。书签复制存储名时有界返回占用，保留历史和单写。
基线 `8a53e738ec6def46f4fdb832167fc6d9949f3eba` / v1.3.0。实施方案 v2.0 SHA-256 `7701befc44b3b50268c5f25c144870f299aff88a11d8640ce406fe6deb3cd85d` 已独立评审通过。

## 当前实现

- `ConversationRef` 使用 hostname 和局部 ID；来源库保留，`pi-tab-history-index` v1 只存标题、来源和 ID。冷读取器使用公共 Storage API，不装载 Harness；源库打开禁止创建/升级。
- 独立扩展历史选择页使用短期文档 grant；选择后订阅原 ref。跨文档恢复只恢复查看选择，执行 lease 不保存。
- 协调器使用 epoch/seq、单来源串行准入、文档 lease 和提交预留；模型页面工具按 documentId、nonce、URL、origin 和路由代次校验。导航失效后须显式重新接续。
- 冷来源存在遗留任务时，整个来源暂停写任务；显式清理逐个等待所有任务，再 inspect 确认排空。
- 书签已有存储名最多等待 1500ms；超时无排队写者，提供重试与显式独立库。拿锁后计时停止；初始化失败撤监听、包装和全局标记并释放锁。

## 复审与交付边界

实现后复审在 `2f32fa5` 确认 worker 单独重启后原页面不能恢复。现为每个 worker 实例生成内存 epoch，原页面经真实文档验证后重新登记与订阅，不恢复旧 lease 或 picker grant；启动通知只联系已启用页面，通知缺失时请求路径有一次有界恢复。纯读取可重试一次，写请求无论明确拒绝还是接受状态未知均不自动重发；确定未提交的输入保留为草稿。没有新增常驻连接或保活轮询。

`test:tabs` 已纳入真实 `ServiceWorker.stopWorker` 生命周期测试：页面、content API 与 offscreen 保持原实例；跨站观察者、过期 picker、缺失启动通知、旧 epoch/lease 拒绝、延迟旧视图、运行中与队列、在途工具、worker 与 offscreen 同时重建及后续 SPA/关闭/受保护页面回归。旧构建原失败断言保留；定向模型请求确认没有盲目重发或重复网页操作。worker 和 offscreen 的 epoch 分别变化，接续仍须显式确认。状态读取按代次和版本应用，防止旧响应清除新授权。

`2f32fa5` 的独立测试已通过真实权限撤销、完整队列和同扩展 ID 回退；本轮恢复改动仍需独立复验和实现后复审。受保护 `chrome://` 页拒绝注入的开发者回归不等同于重新完成所有站点权限设置验收。

独立测试在 `5a8d5bf` 发现 SPA 后无法重新接续，退回实现。根因是 Chrome 的 `MessageSender.url` 保留文档初始 URL：现用内容脚本报告的实时 URL，结合 tabs.get、原 origin、准确 documentId、nonce 和路由代次双向验证后登记；旧文档、旧 URL、错误 nonce 均拒绝。撤权按 tab 串行完成后才登记新路由，迟到的同 URL 更新不会重复撤权。

内容脚本导航时立即撤 lease、取消工具等待、关闭失效选择页并更新界面；重新登记后补齐忙态和历史，丢弃旧路由响应。显式接续等待本次路由同步，避免使用导航前的版本。新增真实按钮回归覆盖 pushState、replaceState、hash、两次后退/前进、取消在途工具后恢复和伪造 nonce 拒绝；修复前原构建失败断言保留。已开始的网页副作用不能自动撤回。
